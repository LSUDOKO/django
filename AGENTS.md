# django

The Web framework for perfectionists with deadlines.

Package manager: npm.

## Commands

- test: `npm test`

## Layout

- `django/`
- `docs/`
- `extras/`
- `js_tests/`
- `scripts/`
- `tests/`

## Rules

- Run `npm test` before you say a change is done.
- Never commit secrets or `.env` files.
